About Me

I am a Front-End Developer in training, interested in transforming ideas into functional, intuitive and visually well-structured interfaces.

My interest in the field comes from the combination of programming, design and user experience. I enjoy understanding not only how an application works, but also how it can provide a good experience for the people who use it.

I am currently improving my knowledge of HTML5, CSS3, JavaScript, ECMAScript and GitHub through courses such as Harvard's CS50, Codecademy, a complete HTML5 and CSS3 course, and a JavaScript and ECMAScript course for beginners.

My main characteristics are creativity, organization, curiosity, willingness to learn and attention to detail.

Whenever I learn something new, I try to understand its fundamentals so that I can apply the knowledge independently.

My goal is to work as a Front-End Developer and eventually work as a freelancer on different projects, developing responsive and accessible interfaces that combine technology, design and a good user experience.

Y2K Calculator

A desktop calculator inspired by the futuristic chrome aesthetic of the Y2K era, combining a custom visual interface with a fully functional calculation system, memory operations and keyboard support.

CATEGORY Desktop Application · Front-End · UI Design
TECHNOLOGIES React · TypeScript · Vite · Electron · Electron Builder · HTML · CSS · JavaScript · Git · GitHub

02

Bloom

A responsive web platform designed to connect animals in need with people willing to help, focusing on responsible adoption, animal reunification and accessible information.

CATEGORY Web Application · Front-End · UI/UX
TECHNOLOGIES HTML · CSS · JavaScript · Git · GitHub
PURPOSE Bloom was created to bridge the gap between animals that need assistance and people willing to provide a safe home, temporary care or other forms of support.
FEATURES Adoption catalog, search filters, individual animal profiles, lost and found records, interactive map, geolocation, animal registration, adoption interest forms, messaging and user profiles.
USER EXPERIENCE The platform provides different user flows for people looking to adopt, people who find an animal and people searching for a lost pet.
DEVELOPMENT I was responsible for the organization and development of the platform, helping turn the team's ideas into a functional and accessible experience.
TEAM The project was developed collaboratively by a team of six members, combining development, design, research and content.
PROJECT CONCEPT Bloom represents the idea of giving animals a new opportunity and creating a more organized connection between people and animal protection initiatives.

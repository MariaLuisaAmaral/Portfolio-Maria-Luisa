## Projects

### Lar Amigo — Animal Adoption and Reunification

Given the large number of abandoned animals and the difficulty of connecting owners, NGOs, and potential adopters in an organized way, I identified the need for an accessible digital solution to support this process.

My team decided to develop, as an academic/personal project, a responsive and accessible front-end web platform for responsible animal adoption and animal reunification, combining UI/UX best practices with technical implementation.

I designed and implemented responsive and accessible interfaces; developed features such as animal registration, search filters, forms, geolocation, user profiles, and a messaging system; applied UI/UX concepts, HTML, CSS, and JavaScript; and managed the project's version control using Git and GitHub.

I deployed the platform online, validating the complete front-end development cycle in practice — from design to production.

## Projetos

### Lar Amigo — Adoção e Reencontro Animal

Diante do grande número de animais em situação de abandono e da dificuldade de conectar tutores, ONGs e adotantes de forma organizada, identifiquei a necessidade de uma solução digital acessível para apoiar esse processo.

Projetei e implementei interfaces responsivas e acessíveis; desenvolvi funcionalidades como cadastro de animais, filtros de busca, formulários, geolocalização, perfil de usuário e sistema de mensagens; apliquei conceitos de UI/UX, HTML, CSS e JavaScript; e organizei todo o versionamento do projeto com Git e GitHub.
